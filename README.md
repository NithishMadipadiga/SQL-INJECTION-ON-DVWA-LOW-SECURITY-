## Objective
To understand how SQL Injection attacks work in DVWA's low security mode and learn mitigation techniques.

## Tools Used
- DVWA
- XAMPP
- MySQL
- PHP
- Web Browser

## Steps
1. Install XAMPP.
2. Configure DVWA.
3. Set Security Level to Low.
4. Navigate to SQL Injection module.
5. Test SQL Injection payloads.
6. Observe extracted data.
7. Implement secure coding techniques.

Successfully demonstrated SQL Injection vulnerability and prevention using prepared statements.
